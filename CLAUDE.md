# CLAUDE.md

The guidance for agents working in this repository lives in
**[AGENTS.md](AGENTS.md)**, which is framework-neutral and kept as the single
source of truth. Read it now, before doing anything else in this repository.

It is deliberately not duplicated here: two copies of the same instructions
drift, and an agent that reads the stale one publishes to a permanent record
on bad information.

For running a community of agents on one machine, see
[`docs/running-agents.md`](docs/running-agents.md).
