# symposium-data commands

Generated by `symposium-data --reference`. Every command prints one JSON object.

## `status`

the data server's status, in either mode

```
symposium-data status [-h] [--data-server-url DATA_SERVER_URL]
```

## `context set`

set the context from a file

```
symposium-data context set [-h] (--community-file COMMUNITY_FILE | --invite-file INVITE_FILE)
```

## `context show`

print the context

```
symposium-data context show [-h]
```

## `admin-config`

manage this server's admin key (R-D4)

```
symposium-data admin-config [-h] --handle HANDLE --data-server-url DATA_SERVER_URL
                                   [--new-key]
```

## `communities create`

create a community

```
symposium-data communities create [-h] --name NAME
```

## `communities list`

list the communities

```
symposium-data communities list [-h]
```

## `roster list`

list the roster

```
symposium-data roster list [-h]
```

## `roster add`

add a handle

```
symposium-data roster add [-h] --handle HANDLE
```

## `roster remove`

remove a handle

```
symposium-data roster remove [-h] --handle HANDLE
```

## `invite`

write a single-use invite file for a roster handle (admin); `invite list --out-dir <dir>` writes every pending invite

```
symposium-data invite [-h] [--handle HANDLE] [--out OUT] [--hours HOURS] list ...
```

## `rebind-key`

retire a member's keys and write a fresh invite file (admin)

```
symposium-data rebind-key [-h] --handle HANDLE --out OUT [--hours HOURS]
```

## `suspect-after`

flag a member's writes after an instant (admin)

```
symposium-data suspect-after [-h] --handle HANDLE --at AT
```

## `purge`

free one version's content (admin)

```
symposium-data purge [-h] --cite CITE
```

## `export`

export the community as a tar (admin)

```
symposium-data export [-h] --out OUT
```

## `import`

create a community from an export, then set the context (admin)

```
symposium-data import [-h] --from FROM_ --community-file COMMUNITY_FILE
```

## `changes`

a page of a collection's changes

```
symposium-data changes [-h] --collection COLLECTION [--since SINCE] [--limit LIMIT]
```

## `stat`

a version's metadata

```
symposium-data stat [-h] [--version VERSION] ref
```

## `get`

download a version to a file, checked against its digest

```
symposium-data get [-h] [--version VERSION] --out OUT ref
```

## `versions`

every version of a file

```
symposium-data versions [-h] file_id
```

## `port-ndex`

port-ndex: copy a community's record from NDEx into the context's empty community (admin)

```
symposium-data port-ndex [-h] --ndex-url NDEX_URL [--page-size PAGE_SIZE] credentials_file
```
